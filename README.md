NGS and Bioinformatics Approaches for Foodborne Microorganism Analysis

Project Overview

This project explores the application of Next-Generation Sequencing (NGS) and bioinformatics approaches for the detection and characterization of foodborne microorganisms.

It focuses on understanding how sequencing technologies and computational tools can help identify microbial communities present in food samples.

Objectives

- Understand the role of NGS in food microbiology.
- Explore 16S rRNA gene sequencing for microbial identification.
- Study microbial diversity and community composition.
- Understand bioinformatics-based sequence analysis.

Workflow

Food Sample Collection → DNA Extraction → 16S rRNA PCR (V3–V4 Region) → Library Preparation → Next-Generation Sequencing → Bioinformatics Analysis → Microbial Identification

Tools and Technologies

- QIIME 2
- DADA2
- SILVA Database
- NCBI
- FastQC

Learning Areas

- Molecular Biology
- Microbial Genomics
- Next-Generation Sequencing
- Sequence Analysis
- Computational Biology

Project Status

Learning and project documentation in progress.
